# pet-adoption-center

A console-based Java application that simulates a pet adoption center where users can adopt, sell, and exchange animals.

## Overview

This project was developed for MIST 4600 to demonstrate object-oriented programming concepts in Java. The application models three categories of animals—birds, mammals, and reptiles—and allows users to interact with the pet shop through a menu-driven console interface.

## Features

- Adopt birds, mammals, and reptiles
- Sell animals to the pet shop
- Exchange animals for different species with price adjustments
- View available inventory
- Object-oriented design using inheritance and method overriding
- Inventory management using Java collections

## Technologies

- Java
- Object-Oriented Programming
- ArrayList
- HashMap
- HashSet
- Scanner

## Project Structure

- `Animal` – superclass containing shared animal attributes
- `Bird`, `Mammal`, `Reptile` – subclasses with species-specific properties
- `Shop` – manages inventory and user interactions

## What I Learned

Through this project I practiced designing an object-oriented application from scratch, creating class hierarchies using inheritance, managing collections of objects with Java data structures, and implementing a menu-driven console application.
